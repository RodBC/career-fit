# Angle: frontend — summary + skills pattern (PT)

## Summary pattern

> Desenvolvedor Front-end com 4+ anos entregando interfaces web em **React** e **TypeScript**, com base sólida em **JavaScript (ES6+)**, HTML5 e CSS3. Constrói componentes reutilizáveis, layouts responsivos e integrações com **APIs REST**; colabora com Backend, QA e Produto em squads ágeis. Foco em qualidade, performance e evolução da arquitetura front-end.

- **Front-end**: React, TypeScript, hooks, componentes reutilizáveis, TanStack Query, Vite; familiaridade com Next.js
- **UI**: HTML5, CSS3, responsividade, design system / utility CSS; loading/erro
- **Integração & qualidade**: APIs REST tipadas, testes (Jest/Testing Library), Git
- **Entrega**: Scrum/Kanban, documentação de componentes, cloud/deploy basics

- Colabora com Backend e stakeholders para traduzir requisitos em fluxos de interface.
