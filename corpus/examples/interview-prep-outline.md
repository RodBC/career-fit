# Interview prep outline (tutoring feature)

1. **What the role actually is** — decode day-to-day in plain language  
2. **Who the interviewer / company is** — public context that shapes their questions  
3. **Why you fit** — map profile facts → their pain (ops volume, API reliability, CRM hygiene, …)  
4. **Stories ready** — 3–5 STAR-ish bullets, not scripts  
5. **Questions to ask them** — show operator curiosity  
6. **Risks / gaps** — name them; prepare honest bridges  

This sits *after* CV + outreach: tutoring for the conversation you just earned.
