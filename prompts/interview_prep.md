# Interview prep (tutoring)

Produce a briefing following `corpus/examples/interview-prep-outline.md`.

## Inputs

- profile (facts + tutoring)
- job description
- optional public notes about interviewer/company

## Output sections

1. Role decode  
2. Interviewer/company context (only from provided notes — do not invent gossip)  
3. Fit map (their pain → your proof)  
4. 3–5 story prompts  
5. Questions to ask  
6. Honest gaps + bridges  

Keep it usable in 10 minutes before a call.
