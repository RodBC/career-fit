# Career Fit — Ecosystem vision

> Long-range product picture. **Wedge first** (tailored CV + reach-out), then expand into a career operating system. UX must stay calm, guided, and human — never a dashboard of anxiety.

## North-star experience

1. **Onboarding dump** — user gives as much as possible up front: deep profile (likes, differentials, gaps, hates, wins, goals) **plus current resume** (PDF/LaTeX/LinkedIn export/paste).  
2. **We structure it once** into a career graph (facts, angles, skills, preferences).  
3. **Ongoing coach loop** — the product keeps suggesting the next high-leverage move and tracks what happened.

This is not “another AI chat.” It is a **living career workspace** with clear objects, status, and next actions.

## Core objects (future data model)

| Object | What we track |
|--------|----------------|
| **Profile / career graph** | Identity, tutoring fields, resume facts, target roles, constraints |
| **Application** | Job, company, angle used, CV version, status (saved → applied → interviewing → offer/rejected) |
| **Outreach** | Recruiter/HM contacted, channel (DM/email), draft, sent?, reply? |
| **Network bridge** | People who can intro or advise (warm paths), relationship note, last touch |
| **Growth action** | Suggested or accepted: course, post topic, project, hackathon, skill drill |
| **Artifact** | Tailored CV, message, interview brief — versioned per application |

## Suggestion engine (after intake)

Once the profile + resume exist, continuously propose (user can accept/dismiss/snooze):

| Category | Examples |
|----------|----------|
| **Reach** | Recruiters/HMs at target companies; peers for warm intros |
| **Network** | People in your graph/area who match the role you’re chasing |
| **Signal** | LinkedIn post topics tied to your differentials (you write/post; we draft outlines) |
| **Skill** | Online courses / certs that close a named gap for target angles |
| **Build** | Portfolio projects that prove the angle you’re selling |
| **Community** | Hackathons, meetups, open-source issues aligned with targets |
| **Apply** | Roles with fit score + ready CV/message pack |

Rules:

- Suggestions must cite **why** (gap, angle, active application, network overlap).  
- Prefer fewer, sharper suggestions over infinite feeds.  
- Never auto-post or auto-DM. Draft → user acts.

## Tracker workspace (CRM for your career)

A single friendly home screen, not a SaaS control panel:

- **Pipeline** — applied jobs with stage + next action  
- **People** — recruiters reached + network helpers  
- **Grow** — curriculum / skill path progress (“advance your curriculum”)  
- **Today** — 1–3 suggested moves max  

UI/UX principles:

- Onboarding feels like a guided interview, not a 40-field form wall (progressive disclosure; resume upload unlocks defaults).  
- One primary CTA per screen.  
- Status language is human (“Waiting on reply from Jane”) not CRM jargon.  
- Mobile-capable later; desktop-first for CV craft now.  
- Calm visual system (we already started this in `web/` — extend, don’t purple-slop).  

## Phased delivery (do not boil the ocean)

| Phase | Ship | Outcome |
|-------|------|---------|
| **A — Wedge (now)** | Profile + resume intake, tailor CV, recruiter drafts | Time-to-interview leverage |
| **B — Memory** | Applications + outreach tracker + artifact versions | Retention; “my career CRM” |
| **C — Coach** | Suggestion cards (courses, posts, projects, people) from profile gaps | Daily reason to open the app |
| **D — Network** | Warm-path suggestions from user-owned exports / pasted graph | Higher reply rates |
| **E — Ecosystem polish** | Beautiful multi-surface UX, mobile, coach/team seats | Expand ACV |

Phase A/B fund the company. C/D are the moat compounding. E is scale.

## Monetization tie-in

- Free: limited tailor + light tracker  
- Pro: full tracker + suggestion engine + interview prep  
- Team/Coach: multi-profile curriculum paths + shared pipelines  

## Explicit boundaries

- Suggestions ≠ spam automation.  
- “Curriculum advance” means **user growth plan**, not rewriting history.  
- LinkedIn posts/courses/hackathons are **recommendations + drafts**, executed by the user (or via green-tier integrations later).
